# ADR-0025：来源会话工作历史失效

日期：2026-10-05。状态：已采用；适用于本地ConversationEngine工作上下文。

## 决定与代价

仅过滤失效长期记忆，不能阻止旧用户原文或助手复述再次进入模型。对有来源事件的语义/情景记忆内容编辑、删除和语义状态变更，程序在记忆写入同一事务内推进来源会话历史截止序号。迁移010新增schemaVersion=1表；截止不保存内容。之后recentContextTurns仅给出截止之后的完整原文，recentTurns保持审计用途，ConversationEngine仅工作记忆改用过滤入口。

按语义猜测删哪些句子不可靠，仅排除来源单句仍会留下复述。因此本步保守清空来源会话截至变更时的短期历史，代价是临时话题连续性损失。长期有效记忆每轮重新检索，新输入保留，其他会话不清空。删除记录后截止仍可重启恢复，失败事务同时回滚记忆与截止。

## 实现边界

来源缺失/无会话时不猜测归属；不会清空全家庭历史。Raw Event和其他派生记忆不自动删除，不保证供应商或DSH服务端历史擦除。无新摘要、依赖或事件类型，不修改已发布迁移。演示为 `npm run demo:history-invalidation`；回归和实测数字见 [progress](../progress.md)，范围见 [设计](../design/history-invalidation.md)。
