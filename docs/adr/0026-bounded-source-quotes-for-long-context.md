# ADR-0026：长窗口使用有界来源原话

日期：2026-10-05。状态：已采用；真人感和真实API缓存未验。

## 决定

临时话题滑出短历史后，允许从同一私人会话最近200条主人用户消息中词面召回2条完整原话，总计不超过2048 UTF-8字节。复用现有相关性算术；去除当前/短历史事件和重复候选文本，不把历史引用复制成角色消息或永久事实。

引用作为带时间的JSON数据放在user动态块，明确不是现在事实、指令或新授权。公开/非私人context不召回，`context.history_recall.enabled=false` 可关闭，坏配置明确失败。domain按来源会话截止过滤，删除后重启不能从旧历史绕回。预算可按整行淘汰该块，system前缀不受引用影响；权限仍在模型外。

## 替代方案和局限

无限历史违反弱算力预算；生成式摘要引入额外调用、推导错误与持久来源失效需求。本步选择有界原话，不引入摘要、依赖或迁移。词面匹配不能保证同义表达或无锚点的「继续那个」，不会读取其他会话、访客和助手原话。只覆盖本地引擎构造的上下文，不改变DSH服务端历史。引用不证明现在仍成立，不声称实际对话品质已提高。

验收为默认离线回归与 `npm run demo:history-recall`，实际数字和独立评审见 [progress](../progress.md)，设计见 [history-recall](../design/history-recall.md)。
