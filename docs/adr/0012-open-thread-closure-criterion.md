# ADR-0012：未完话题的收口判据（对象词门槛 + 宁可再问一次）

- 状态：已采纳（2026-10-01）；**判据已升级到「词 / 对象」级**（第五轮 t2，见「§判据升级」）——t8 记下的两条
  「共享内容字」残余已实测消失，真答案召回没有下降
- 相关：铁律 1（规则与判断由程序负责）、铁律 4、铁律 12（新增依赖必须写理由）、pack §9 与 §10
  （TopicEngine / OpenThread）、[ADR-0011](0011-proactive-decision-ownership.md)、`docs/progress.md` §2.19、
  `docs/design/conversation.md`

## 背景

第四轮 t3 落地「第二天追问」（`OpenThreadStore` + `TopicEngine`）之后，t7 评审查到一处会**永久丢事**的缺陷：
`reconcile` 把追问之后的**第一条**用户轮次无条件当成回答，于是用户随口聊一句天气就会把话题静默收口。
实测：话题「明天我要去买药。」下，用户答「今天天气不错啊。」→ 话题判 `engaged`、次日候选为 0，真正的追问再也不会发生。
同类问题还有一处：弱证据路径用**未过滤**的字表比字，「我今天没去散步。」这类也会被 `snoozed`（同样是终态）。

## 决策

1. **收口必须与被问的那件事挂钩**：只有回答里出现话题的**对象词**（没有对象词时是有辨识度的动作词）才收口
   —— t8 先把判据收成**一条规则**并删掉等价的弱证据分支；第五轮 t2 再把比对的单位从**字**换成**词**（见下）。
2. **对不上的轮次不动状态**：记进 `ReconcileResult.ignored`——**不写事件、不改状态**，话题保持 `offered`。
3. **宁可再问一次**：由既有的 `reofferAfterMinutes` / `maxAttempts` / `expireAt` 在窗口内把它放回候选——
   不新增机制，也不会没完没了地问（问满 2 次照旧 `exhausted`）。
4. **不用 `snoozed`**：它属已收口状态（`OPEN_THREAD_SETTLED_STATUSES`），会**永久**关掉话题，与第 3 条冲突。
5. **扫描范围含 `candidate + lastOfferedAt`**：回到候选、还没被再问之前他就答了那件事时，不该再问第二遍；
   前置条件严格（仅 `lastOfferedAt` 非空且轮次严格晚于它），不新增状态或写路径。

## 判据升级（2026-10-01，第五轮 t2）

### 为什么升级

t8 的判据是**字**级：回答里只要出现话题的一个**内容字**就算在回答那件事。换个话题主题时，**共享一个
内容字**的无关句就会被算作相关、把话题写进终态：

| 话题 | 无关句 | 共享的字 | t8 实测 |
|---|---|---|---|
| 明天我要去买药。 | 我去楼下买了点水果。 | 买（通用动词） | 1/13 |
| 明天我要去看孙子。 | 老李家的孙子回来了。 | 孙子（常见名词） | 1/13 |

### 升级后的判据（`isAnswerAboutThread`，仍是纯函数、一条规则）

比对的单位是**词与对象**，不是「碰巧共享的一个字」。词表是 `OBJECT_WORDS` / `ACTION_WORDS`，被排除的
通用动词在 `FRAME_WORDS`（三张表的关系由**模块加载时**的 `assertVocabularyShape()` 把关：通用动词不许
同时是收口依据）。回答必须满足下面之一：

1. **说了话题里的东西**：回答里的对象词与话题的对象词有交集 ——「证已经拿到了」对「办证」（词形 `证` 是
   `办证` 的一部分）、「药买回来了」对「买药」、「孙子不在家，没见着」对「看孙子」；
2. **说了话题的动作**：回答说了**话题的动作词**，而且说得一样完整 ——「办好了」「还没办」对「办证」（都是
   「办」）。通用动词不算：「买 / 看 / 吃 / 拿 / 去 / 来 / 做」在换一件事时照样出现（买药 / 买水果 / 看电视 /
   看孙子），它们编在 `FRAME_WORDS` 里，**永远不能单独作为收口依据**；
3. **不是别人的东西**：对象对上了，但如果回答把它换进了**别人的**框里（「老李家的孙子回来了。」
   「隔壁老王家孙子回来了。」），而话题里没有那个定语，则不算回答 —— 除非回答同时说得出话题的动作词。

### 两条残余的实测结果

| 项 | t8（字级） | t2（词 / 对象级） |
|---|---|---|
| 收益：无关句被误判为回答（13 句探针） | 办证 0/13、复诊 0/13、理发 0/13；**买药 1/13、看孙子 1/13** | **7 个话题全部 0/13**（0/91；两个靶子买药 / 看孙子 实测由 1/13 降到 0/13） |
| 召回：t8 那张真答案表（9 句，话题「去镇上办证」） | 7/9 收口 | **7/9 收口**（同样的两句不收口，见下） |
| 召回：升级后补的真答案探针（7 个话题共 15 句） | —— | **15/15 收口** |

真答案召回**没有下降**，被钉住的两句（「没去成，改天再说吧。」「不去了。」）行为**刻意保持不变**：
它们一个字都没提到那件事，**在字面上与「今天没去成。」无法区分**（可能是没去成那件事，也可能是没去成散步）。
判据说「不算回答」时话题留在 `offered`：`reofferAfterMinutes` 之后可以再问一次，而且是**有界**的
（`maxAttempts` 2 次之后 `exhausted`，每一次还要过主动引擎的硬门禁与社会预算）；反过来「猜它是回答」会把话题
写进**终态、不可重开**的 `snoozed`/`resolved` —— 静默丢一件事是**无界**的。取舍的代价因此是「多问一次」。
`t2 边界` 与 `t2 探针表` 两条用例把这两个期望都钉住（改探针表必须一起改用例）。

### 代价与已知边界（如实记）

1. **对象词表是受控清单，不是分词器**：`OBJECT_WORDS`（药 / 证 / 孙子 / 材料 / 复诊 / 理发 / 电视…）与
   `ACTION_WORDS`（办 / 取 / 交 / 修 / 复诊 / 理发…）是**领域词表**，不是通用词典。没登记进来的名词等于
   没有对象词 —— 那时判据退回到动作词那条（与 t8 之后的行为一致，**不会比字级更糟**）。
   加词是改词表，不是改判定逻辑；仓库因此**没有引入任何新依赖**（铁律 12：无需写新增理由）。
2. **「别人的」是一个小词表**：姓氏 + 家（`老李家的`）、隔壁、邻居、人家；第一人称定语（`我家的`）与否定式
   （`孙子不在家`）不算。没覆盖到的写法（方言昵称、更复杂的定语）最坏退化到 t8 的行为（1/13）。
3. **动作词要说得一样完整**：回答里的**短**动作词被话题**长**动作词盖住不算数。否则「拿」会对上「拿药」，
   「东西拿到了」就会被当成回答了「去拿药」—— 那还是「共享一个字」。代价：话题「拿药」下，
   「拿回来了。」（只说了一半、没提药）不收口，留在窗口里可以再问一次。
4. **动作词不进 `ACTION_WORDS` 的通用动词**（买 / 拿 / 看 / 吃 / 去 / 来…）：话题是「买药」时，共用一个
   「买」的「我去楼下买了点水果。」不再收口；代价是话题「买东西」这类**只有通用动词**的话题退回「等过期」。
