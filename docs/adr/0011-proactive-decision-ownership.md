# ADR-0011：主动开口的决定权归谁（硬底线 + 模型读空气）

- 状态：已采纳（2026-10-01）
- 相关：铁律 3、[ADR-0009](0009-proactive-triggers-and-hard-gates.md)、`xixi_v02_refactor_pack` Phase 5、`docs/design/conversation.md`

## 背景

铁律 3 原文是：

> 主动行为必须先过确定性硬门禁（静默时段 / 冷却 / 当日额度 / 重复话题 / 对话冲突 / 置信度），LLM 不能绕过。

这套实现（ADR-0009）把十个分量等权平均成一个分数，再与阈值比较：**单一阈值一票否决**。实测后果是
「不像住在家里的熟人」——主动开口被固定冷却与阈值压成定时播报，话题只能来自很薄的来源
（在场 / 长时间安静 / 时间钩子 / 上一条用户发言），**没有「读空气」**。

`xixi_v02_refactor_pack` 的 Phase 5 指出：**高主动性 != 高频打扰**，应当把「要不要说」拆成
话题质量分、社会预算、读空气（receptivity）、未回应惩罚、话题重复惩罚等**多个可解释的信号**，
而不是一个阈值；并允许「正在热聊时可以连续接话，不受新会话冷却限制」。

用户 2026-10-01 明确指示：社会预算 / 读空气 / 未回应惩罚 / 话题质量分按该包来做，
并且 **「模型可以决定要不要说话」**。

## 决定

主动行为分两层：

1. **硬底线（程序判定，模型不可绕过）**：静默时段、当日额度、费用上限、隐私与同意。
   这些是**不可协商**的边界——它们是安全与成本约束，不是「语气」问题。
2. **硬底线之外，是否开口由模型读空气决定**：确定性评分只提供**候选与依据**
   （话题质量分 / 社会预算 / 读空气 / 未回应惩罚 / 话题重复惩罚），**不再由单一阈值一票否决**。
   模型可以说「不说」；这个选择与理由同样要落库。

铁律 5 不变：**不存模型私有推理**，只存 `reason_code` 与分数。因此「模型决定」的可审计形式是
——决策记录里带上候选的分数、模型给出的 `reason_code`，以及它是「说了」还是「选择不说」。

## 后果

- **正面**：主动行为从「定时播报」变成「有理由、会读空气」；用户可以要求更主动而不必担心被骚扰；
  热聊中可以连续接话（不再被新会话冷却卡住）；每个决定都有分数与理由可复核。
- **代价（必须诚实记录）**：
  - 主动性不再由单一阈值保证「频率上限」，**行为更依赖模型判断**，因此**必须**保留硬底线，
    否则静默时段与费用会失守；
  - 需要新的验收方式：12 小时时间线模拟（主动次数区间、generic 话题占比、未回应后降频、
    热聊中连续接话），而不是「阈值 0.495 是否生效」；
  - 「读空气」的质量取决于候选质量——**没有未聊完话题与记忆时，话题质量分只能在薄来源上打分**
    （P3/P4 之后才会真正变好）。
- **不变**：静默时段 / 额度 / 隐私路径 / 不编造可核查事实 / 事件溯源与审计，全部照旧。

## 备选方案

1. **保持单一阈值一票否决**（原状）：可控、可测，但用户实测「远低于预期」，主动性像定时播报。
2. **全部交给模型决定**（含静默时段与额度）：最像人，但**静默时段与费用会失守**，且违反铁律 1
   （规则与边界由程序负责）——**不采纳**。
3. **两层（本决定）**：硬底线仍由程序判定，硬底线之上由模型读空气——同时满足「像人」与「不失守」。
