# ADR-0023：有界原文上下文与动态情境分离

日期：2026-10-05。状态：已实施（S3第一步软件范围）。

## 问题与选择

旧历史只限制8条，不限制字节；respond先落库后组提示，当前用户事件被再读进history。心情和听众随场景改变system，稳定前缀缺少可核对边界。

选择完整原文的有界历史后缀＋每轮有效记忆检索。扩大窗口增加输入；生成式滚动摘要需要新来源/版本/失效协议，本步不加入。按事件ID排除当前轮次，重复原话不按文本删除。人格变化仍可改变前缀，心情/听众放到user情境中；程序权限与隐私过滤不变。

## 预算定义与失败

context.budget限制system、history、user的UTF-8文本字节，默认总量32768、历史8192。硬政策、完整当前输入与必要情境先保留；超出时明确失败，不调用模型。先删最旧完整历史，再减关系/未完话题/记忆的末尾整行，不编造摘要。诊断仅数字、版本和system摘要，不持久化原文或模型推理。

这是文本预算，不计工具schema、工具结果、图片、HTTP/JSON开销，也不等于供应商token或金额上限。工具循环/真实缓存usage测量、真人感同语料对比与首字延迟仍后续。私人/公开模式context层是否启用不同，可产生不同前缀；按分区核对稳定，不能跨分区宣称同一缓存。

## 证据与局限

测试覆盖当前事件去重、场景前缀稳定、完整消息/记忆行淘汰、固定块超量、真实配置接线、长会话关闭重开数据库、有效记忆替代/撤销和访客隔离；命令 `npm run demo:context`。数字见 [progress](../progress.md) 的S3第一步段。

演示的记忆替代/撤销通过MemoryStore程序接口，不把它写成新的自然语言纠正能力；既有纠正器单独有测试。原始对话历史属于发生过的事，仍保留引用；本步不保证删除记忆同步删除所有历史原文，不引入缓存摘要，因此不存在本步摘要复活旧事实。跨窗口临时话题连续性、原文删除传播与模型效果仍未验。

没有新依赖或迁移，不使用GPU、后台服务或外网。
