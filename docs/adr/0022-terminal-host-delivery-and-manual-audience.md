# ADR-0022：终端宿主拥有交付账本与人工身份边界

日期：2026-10-05。状态：已实施（S2软件范围）。

## 原因

模拟AmbientRuntime已经有审批和durable提醒，旧终端仍直接调用对话引擎，无法把工具成功、打印交付与重启恢复连接起来。当前没有设备，不能把输入文字当作摄像头或声纹识别。

## 决策与实现

chat直连/fake通过TerminalCompanion使用统一宿主，默认公开，人工声明独处才使用私人上下文及主人写权限。声明本身不跨进程保存；静默、同意、审批和提醒持久化。人的输入刷新在场证据，15秒idle tick不刷新；执行工具和交付用实时钟检查60秒TTL。

全部段打印成功才完成输出并确认提醒投递；失败输出中断，恢复时不自动重复播放。程序replyGuard读取本轮失败写工具结果，在记录/输出前修正完成宣称，启用时暂存流式文本。它没有证明所有无工具幻觉都被消除。

DSH工具不能证明都经过宿主registry，保留旧路径并明确范围；不将Harness API移出brain-adapter。无新增依赖和迁移。其他入口、真实设备、费用金额上限与长时间资源治理留待后续阶段。

## 证据与代价

实际fake CLI两进程demo恢复审批、提醒、会话和静默；HTTP/SSE替身验证真实模型客户端与工具表；全量数字见 [progress](../progress.md) 的S2段。没有真实API/硬件/断电证据。等待完整回复再交付可能增加首字延迟，S3须在保持事实保护的前提下验证自然度和上下文预算。
